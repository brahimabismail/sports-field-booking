# ⚽ تطبيق حجز الملاعب الرياضية (Sports Fields Booking App)

## 📌 1. وصف المشروع (Project Description)

يهدف هذا المشروع إلى تطوير تطبيق للهاتف المحمول يسمح للمستخدمين بحجز الملاعب الرياضية، وخاصة ملاعب كرة القدم، بطريقة سهلة وسريعة.

يسمح التطبيق للمستخدم بالاطلاع على قائمة الملاعب المتاحة، ومعرفة معلومات كل ملعب مثل الموقع والسعر والصور، ثم اختيار التاريخ والوقت المناسبين وإتمام عملية الحجز.

يسعى المشروع إلى تسهيل عملية الحجز، وتوفير الوقت والجهد على المستخدمين وأصحاب الملاعب.

## 🎯 2. أهداف المشروع (Project Objectives)

- تسهيل عملية البحث عن ملاعب كرة القدم.
- عرض الملاعب المتاحة للحجز.
- توفير معلومات حول الأسعار والمواقع.
- السماح للمستخدم باختيار تاريخ ووقت الحجز.
- تأكيد الحجز بطريقة إلكترونية.
- تجنب تداخل الحجوزات في نفس الوقت.
- مساعدة أصحاب الملاعب على إدارة الحجوزات.

## 🛠️ 3. الوظائف الرئيسية (Main Features)

### 👤 بالنسبة للمستخدم (User)

- إنشاء حساب جديد وتسجيل الدخول.
- تصفح قائمة الملاعب الرياضية.
- البحث عن الملاعب حسب الموقع.
- عرض تفاصيل الملعب (الاسم، الصور، السعر، الموقع).
- الاطلاع على الأوقات المتاحة.
- اختيار تاريخ ووقت الحجز.
- تأكيد الحجز.
- عرض الحجوزات السابقة والحالية.
- إلغاء الحجز.

### 🏟️ بالنسبة لصاحب الملعب (Field Owner)

- إضافة ملعب جديد.
- تعديل معلومات الملعب.
- حذف ملعب.
- تحديد أسعار الحجز.
- تحديد أوقات العمل والتوفر.
- متابعة الحجوزات.
- قبول أو رفض الحجوزات عند اعتماد نظام الموافقة اليدوية.

### 🔐 بالنسبة للمسؤول (Admin)

- إدارة حسابات المستخدمين.
- إدارة الملاعب المسجلة.
- مراقبة الحجوزات.
- إدارة التطبيق ومتابعة نشاطه.

## 🔄 7. طريقة عمل التطبيق (How It Works)

1. يقوم المستخدم بفتح التطبيق.
2. يسجل الدخول أو ينشئ حسابًا جديدًا.
3. يتصفح قائمة الملاعب المتاحة.
4. يختار الملعب المناسب.
5. يطلع على تفاصيل الملعب وسعر الحجز.
6. يحدد تاريخ ووقت الحجز.
7. يتحقق التطبيق من توفر الملعب في الوقت المحدد.
8. يؤكد المستخدم عملية الحجز.
9. يتم حفظ الحجز في قاعدة البيانات.
10. يستطيع المستخدم الاطلاع على تفاصيل حجزه.
